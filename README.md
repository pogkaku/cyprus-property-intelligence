Project Overview

Cyprus Property Intelligence is a data analytics project that collects, cleans, processes, analyzes, and visualizes residential property listing data from Cyprus.

The project aims to transform publicly available property listing information into a structured dataset that can support exploratory market analysis and interactive data visualization.

Project Objectives

- Collect residential property listing data through web scraping.
- Clean and standardize property attributes.
- Process the cleaned data into a dashboard-ready dataset.
- Perform exploratory data analysis (EDA).
- Analyze property prices, price per square metre, covered area, bedrooms, bathrooms, and districts.
- Develop an interactive dashboard using Looker Studio.

Project Pipeline

1. Web Scraping — Extract property listing information from INDEX.cy.
2. Data Cleaning — Handle missing values, standardize categorical fields, and clean numerical attributes.
3. Data Processing — Prepare the cleaned data for downstream analysis and visualization.
4. Exploratory Data Analysis — Generate descriptive statistics and visualizations.
5. Dashboard Dataset Preparation — Select and organize the fields required for the dashboard.
6. Interactive Dashboard Development — Visualize property market information using Looker Studio.

Technologies Used

Installation and Setup

1. Clone the repository

git clone <your-repository-url>
cd cyprus-property-intelligence

2. Create a virtual environment

python3 -m venv .venv

3. Activate the virtual environment

On Linux or macOS:

source .venv/bin/activate

4. Install dependencies

pip install -r requirements.txt

Running the Project

Run the scripts from the project root directory.

1. Scrape property listings

python src/scraper.py

This collects property listing information and saves the raw dataset under "data/raw/".

2. Clean the data

python src/cleaner.py

This cleans and standardizes the raw property dataset.

3. Prepare the dashboard dataset

python src/processor.py

This selects the required property attributes and prepares the dashboard dataset.

4. Run exploratory data analysis

python src/analysis.py

This generates charts and saves them under "outputs/analysis/".

Note: The scripts depend on the input files generated by the preceding stages. Run them in pipeline order when rebuilding the project from scratch.

Dataset Description

The raw dataset contains the following property attributes:

Column| Description
"property_id"| Property listing identifier
"title"| Listing title
"location"| Property location information
"price"| Asking price
"price_per_m2"| Price per square metre
"bedrooms"| Number of bedrooms
"bathrooms"| Number of bathrooms
"covered_area"| Covered property area
"parking"| Parking information
"floor"| Original floor information

The cleaned dataset also includes derived fields such as "district", "floor_number", and "total_floor".

The final dashboard dataset contains the selected fields required for visualization, including the district and numeric floor attributes.

Exploratory Data Analysis

The analysis explores relationships and distributions involving:

- Average property price by district.
- Average price per square metre by district.
- Property price versus covered area.
- Price, price per square metre, and covered-area distributions.
- Average price by number of bedrooms.
- Average price by number of bathrooms.
- Distributions of bedrooms, bathrooms, and floor information.

Generated visualizations are stored in "outputs/analysis/".

Interactive Dashboard

Looker Studio is used to develop an interactive dashboard from the processed property dataset.

The dashboard is intended to help users explore property prices, district-level differences, property characteristics, and price per square metre.

The dashboard link and screenshots can be added to the "dashboard/" directory or linked here once finalized.

Limitations

- The current dataset contains 24 property listings and is a small exploratory sample.
- Listings may not represent the entire Cyprus residential property market.
- Missing or unavailable listing attributes may affect some analyses.
- Listing prices are asking prices and may differ from final transaction prices.
- Web page structures and availability can change, potentially requiring scraper updates.

Consequently, the current findings should be interpreted as exploratory rather than as definitive market estimates.
